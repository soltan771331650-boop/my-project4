# الطابعة المثالية — نسخة جاهزة للبناء من الهاتف

هذا مشروع **Native Android / Kotlin**، وليس Flutter ولا React Native.

## ما الذي تم تجهيزه؟

- IPP/IPPS كمسار الطباعة الأساسي عند توفره.
- DNS-SD / mDNS لاكتشاف خدمات `_ipp._tcp` و`_ipps._tcp` و`_printer._tcp`.
- Wi-Fi Direct DNS-SD Service Discovery.
- `bindProcessToNetwork()` لمحاولة توجيه اتصال التطبيق إلى شبكة Wi-Fi المحلية حتى لو لم يكن فيها إنترنت.
- استعلام قدرات الطابعة عبر IPP قبل اختيار صيغة المستند.
- PDF والصور كمدخلات.
- A4، ملون، تدرج رمادي، أبيض وأسود، وعدد النسخ.
- RAW TCP على المنفذ 9100 كمسار توافق احتياطي.
- واجهة عربية بسيطة.
- GitHub Actions لبناء APK من الهاتف إذا أردت البناء السحابي.

## الطريقة الأولى: AndroidIDE على الهاتف

AndroidIDE يدعم فتح مشروع Gradle موجود على الهاتف. الوثائق الرسمية تذكر أن المشاريع الموجودة يمكن فتحها مباشرة، وأن AndroidIDE يحتاج أدوات البناء وJDK المناسبة. كما أن AGP 7.2.0 أو أحدث مدعوم. المشروع هنا يستخدم AGP 9.4.0 وGradle 9.6.0 وJDK 17، وهي إصدارات متوافقة بحسب ملاحظات Android الرسمية لـ AGP 9.4.0.

1. فك ضغط الملف.
2. افتح AndroidIDE.
3. اختر **Open existing project**.
4. اختر مجلد `NativeWifiPrinter` نفسه، وليس ملف ZIP.
5. انتظر انتهاء Gradle Sync.
6. اضغط Run / Quick Run.
7. سيُبنى `app-debug.apk` ويمكن تثبيته على الهاتف.

> أول مزامنة قد تحتاج إنترنت ووقتاً لتنزيل Gradle والاعتمادات.

## الطريقة الثانية: البناء من GitHub من الهاتف

المشروع يحتوي على:

`.github/workflows/build-apk.yml`

بعد رفع المشروع إلى مستودع GitHub، شغّل Workflow باسم **Build Android APK** من تبويب Actions. سيبني ملف APK Debug ويرفعه كـ Artifact.

## ملاحظة مهمة عن الطباعة

لا يوجد Driver RAW واحد مضمون لكل موديلات Epson وHP وغيرها. لذلك لا يرسل التطبيق PDF أو PWG Raster عشوائياً إلى 9100. الأولوية هي IPP واكتشاف القدرات، ثم استخدام المسار الذي تعلنه الطابعة. RAW 9100 موجود كخيار توافق، ويحتاج اختباراً على موديل الطابعة الفعلي.

## قبل الاختبار

- الهاتف والطابعة على نفس شبكة Wi-Fi، أو استخدم Wi-Fi Direct إذا كان الموديل يدعمه.
- امنح التطبيق صلاحية الأجهزة القريبة عند طلبها.
- اضغط اكتشاف الطابعات.
- اختر PDF أو صورة.
- اترك المسار والمحرك على تلقائي في أول تجربة.
- اختر A4 واللون وعدد النسخ.

## حدود النسخة الحالية

هذه نسخة هندسية قابلة للبناء والتطوير، وليست ضماناً بأن كل موديلات الطابعات ستعمل من أول محاولة. دعم الطابعات المختلفة يعتمد على قدرات كل موديل وبروتوكولاته.
